# Maliha Zahan Chowdhury - Academic Portfolio

This folder contains the complete static website for `https://malihamima.github.io`.

## Publish with GitHub's website interface

1. Sign in to GitHub and open your existing `malihachowdhury.github.io` repository.
2. Open **Settings**. Under **General**, rename the repository to `malihamima.github.io`.
3. Return to the **Code** tab.
4. Delete any placeholder files you do not need.
5. Choose **Add file → Upload files**.
6. Upload `index.html`, `.nojekyll`, `README.md`, and the complete `assets` folder from this package. The files must be at the repository root; do not upload the outer `MalihaMima.github.io` folder itself.
7. Select **Commit changes**.
8. Open **Settings → Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Select the `main` branch and the `/(root)` folder, then save.

GitHub normally publishes the site within a few minutes. Visit:

`https://malihamima.github.io`

## Update the CV later

Replace `assets/CV_Maliha_Zahan_Chowdhury.pdf` with the updated PDF while keeping the same filename.

## Update text later

Open `index.html` on GitHub, choose the pencil icon, edit the relevant text, and commit the change. The visual design is contained in `assets/portfolio.css`.

## Files

- `index.html` - portfolio content and structure
- `assets/portfolio.css` - responsive visual design
- `assets/CV_Maliha_Zahan_Chowdhury.pdf` - downloadable CV
- `assets/favicon.svg` - browser icon
- `.nojekyll` - ensures GitHub Pages serves the static files directly
